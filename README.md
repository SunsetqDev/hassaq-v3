# Hassaq — сайт v3 (меню в стиле Burger King, казахский стиль)

Сайт кафе быстрого питания **Hassaq** (Актобе). Чистый HTML/CSS/JS + GSAP с CDN, без сборки.

## Запуск
```bash
python -m http.server 5173
```
Открыть http://localhost:5173 (нужен сервер, а не двойной клик по файлу — иначе не грузится музыка и часть скриптов).

## Где что
- `index.html`, `styles.css`, `main.js` — страница
- `menu*.js` — меню (позиции, цены, фото — из Яндекс Еды Hassaq; пиццы — из Instagram)
- `i18n.js` — тексты на русском и казахском
- `order.js` — окно заказа через Glovo / Яндекс Еду
- `music.js` + `assets/music.mp3` — фоновая музыка («Көңіл толқыны»)
- `assets/menu/` — фото блюд
